# CS-320

1.) How can I ensure that my code, program, or software is functional and secure?

  I ensure that my code, program, or software is functional and secure by writing comprehensive unit tests, such as using a tool like JUnit, to verify that every method and class runs as expected according to the requirements of the project. I break down the code into smaller pieces so that I can test as I go instead of writing all the code at once; this also saves time because it is quicker to spot errors. I also apply protective and defensive programming techniques such as boundary checks, like ensuring max-length constraints on names and IDs, and proper error handling. 

  
  2.) How do I interpret user needs and incorporate them into a program?

  I interpret user needs and incorporate them into a program by understanding that user stories or project objectives need to be analyzed for edge cases like empty submissions, null inputs, and values that are out of range; they need to also be mapped precisely into my logic or the database constraints. I also translate the requirements by reading them thoroughly and breaking them down into solid rules, for example, converting the rule "names can't be null or exceed 10 characters" into functional code like an if statement or validation check.

  How do I approach designing software?

  3.) I approach designing software by first perusing and taking note of the requirements and problem statements to make sure I am on the right path to meeting the standards of the project. I build the software in components that are manageable, design clean interfaces, and write tests with or after implementation to spot and clear any design flaws early in the process.
